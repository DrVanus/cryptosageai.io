# CryptoSage website design

## 2026-10-30 — Gold observatory

The user selected variant 1, Gold observatory, after viewing two working HTML directions. Preserve the established gold owl identity, introduce a deep teal night sky, sparse stars and orbital/constellation geometry, and use a serif accent only for the hero word “explained.” The atmosphere is CSS/SVG, with no generated bitmap or continuous background animation.

The existing site and real 1.3.14 app captures are the visual references. Desktop hero copy and actions align together; the mobile layout reflows, including at 200% text. Screens are deliberately selected rather than auto-crossfaded so text never overlaps. Gallery images can be enlarged using pointer or keyboard.

Core copy stays readable if scripts or third-party resources fail. Navigation, FAQ and pricing have explicit state semantics; the optional newsletter loads Firebase only on submission. Inter is self-hosted under its SIL Open Font License. Supporting pages share the same visual tokens.

The old competitor scorecard was removed because it had no maintained evidence. Advice-like or unconditional marketing claims were softened, and the sample chat is labelled illustrative. Existing legal provisions are unchanged. Demo/illustrative portfolios are labelled beside screenshots; no screenshot pixels were fabricated or cosmetically edited.

Screenshot provenance and exclusions are in screenshot-provenance.json. The canonical audit overlay lists exactly the currently referenced assets.
